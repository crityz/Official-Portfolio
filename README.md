# James Dominic T. Ortega — Portfolio

A React, TypeScript, and Vite portfolio site.

## Run locally

```sh
npm install
npm run dev
```

## Build and preview

```sh
npm run build
npm run preview
```

## Deploy to Vercel

Push this repository to GitHub, then import it as a new Vercel project. The included `vercel.json` sets the Vite framework, `npm run build` command, `dist` output directory, and a fallback rewrite for SPA routes. Use the repository root as the project root; Vercel can install dependencies from `package-lock.json`.
